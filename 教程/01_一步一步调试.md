# 一步一步调试（面向 Python 初学者）

本文目标：带你从 0 到 1 跑通这个项目，并能看懂每一步在做什么。

## 0. 先建立心智模型

这个项目有两条主线：

1. Agent 规划线：把自然语言 Prompt 变成 Pipeline（步骤图）。
2. Runtime 执行线：按 Pipeline 执行每个节点，得到输出。

一句话总结：

`Prompt -> Agent 组装 Pipeline -> Engine 执行 Pipeline -> 输出结果`

## 1. 入口文件在哪里

核心入口是 `test.py`。

你会看到：

- `PROMPT`：任务说明文本。
- `agent = ReactLoopAgent()`：创建规划器。
- `result = await agent.run(PROMPT)`：让模型通过工具调用来组装 Pipeline。
- `engine = PipelineEngine()` + `run_pipeline(...)`：真正执行 Pipeline。

## 5. 关键模块职责

- `agent/react_loop.py`：控制大模型循环、处理 tool call、控制终止条件。
- `agent/tools.py`：提供通用工具（add/update/connect/get_catalog/get_details/get_pipeline）。
- `engine/core/engine.py`：统一执行入口。
- `engine/core/scheduler.py`：根据依赖关系调度步骤。
- `engine/core/context.py`：存储输出、解析 `$step_id['field']` 引用。

## 6. 重要节点做什么

- `trigger.manual`：注入初始输入（如 `universe`）。
- `data.market_bars`：优先 BaoStock 拉取日线，失败时尝试 fallback 数据集。
- `factor.momentum`：按窗口计算动量分数。
- `factor.rank`：按分数排序并产出 rank。
- `research_chat`：调用 LLM 生成解释文本。

## 7. 你最关心的 Output 在哪里

- 在 `test.py` 里，最终会打印 `run_result["outputs"]`。
- 每个 key 对应一个 step 的输出（例如 `bars`、`momentum`、`rank`、`chat`）。

## 8. 常见错误与定位

1. `OPENAI_API_KEY` 未设置：
   - 错误点在 Agent 或 `research_chat` 节点。
2. BaoStock 网络不可达：
   - `data.market_bars` 可能报连接错误。
3. 引用写错（如 `$rank['foo']` 字段不存在）：
   - 调度阶段或节点执行阶段报错。

建议定位顺序：

1. 先跑 `tests/run_tests.py`
2. 再跑 `教程/step_by_step_debug.py`
3. 最后跑 `test.py`
