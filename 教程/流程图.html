Quant React Interview 执行流程图

把项目当成两段流水线：先由 Agent 组装 Pipeline，再由 Runtime 执行 Pipeline。调试时建议先看 Runtime，再看 Agent。

一、全局主流程

Prompt 输入test.py 里的 PROMPT
→
Agent 规划ReactLoopAgent.run()
→
生成 PipelineJSON steps + next + config
→
Runtime 执行PipelineEngine.run_pipeline()
→
最终输出run_result["outputs"]

二、Agent 内部时序

Agent

1) 建立对话上下文

system prompt + user prompt，准备 tools schema。

Agent

2) 调用模型

请求 /chat/completions，让模型决定是否发起 tool calls。

Agent

3) 执行工具

add_step/update_step/connect_steps/get_catalog/get_details/get_pipeline。

Agent

4) 错误修复与终止

遇到失败会注入 repair hint，达到上限或 get_pipeline 成功后结束。

三、Runtime 执行时序

Runtime

1) 解析与校验 DSL

读取 YAML/Dict，校验 step id 唯一性与依赖合法性。

Runtime

2) 构建依赖图

同时识别 next 边和 $step_id['field'] 引用依赖。

Runtime

3) 分批执行就绪节点

解析 config 引用后执行节点，把输出写入 context。

Runtime

4) 汇总 outputs

返回 { status: "success", outputs: ... }。

四、推荐调试顺序

调试

Step A

先跑 python3 tests/run_tests.py，确保 Runtime 底层正常。

调试

Step B

跑 python3 教程/step_by_step_debug.py examples/momentum_pipeline.yaml，逐步看输入输出。

调试

Step C

最后跑 python3 test.py，验证 Agent + Runtime 全链路。
